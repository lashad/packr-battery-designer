# Packr – 18650 Battery Pack Designer

Packr is a lightweight web application for designing and visualizing custom **18650 battery pack configurations** like 3S8P, 4S6P, etc. It's perfect for hobbyists, engineers, and educators who need a simple and visual layout tool for prototyping battery systems.

---

## 🔧 Features

- 📦 Create and preview battery packs in custom S/P configurations
- 🎯 Position and animate each cell in 3D using Babylon.js
- 🧭 Quick camera views: front, back, left, right, and home (CAD-style)
- 🖱️ Intuitive controls for layout, spacing, and orientation
- 💾 Save/load scenes locally (JSON export support)
